کاملاً آفلاین بعد از نصب

این نسخه، عبارت‌های کوتاه و از پیش تعریف‌شده را می‌شناسد. برای هر فرمان سه نمونه با صدای طبیعی ضبط کن. هر ضبط ۲٫۵ ثانیه است؛ بلافاصله بعد از شروع حرف بزن. حداقل دو فرمان باید هرکدام دو نمونه داشته باشند.

دربارهٔ تشخیص صدا و استفادهٔ مستقل

تشخیص، با مقایسهٔ ویژگی‌های صوتی MFCC و DTW روی خود ESP32-S3 انجام می‌شود و به صدای آموزش‌دهنده وابسته است. این روش تبدیل گفتار به متن یا مکالمهٔ آزاد فارسی نیست. دقت واقعی پس از آموزش با میکروفون شما مشخص می‌شود. برای کار بدون کامپیوتر، میکروفون I2S و آمپلی‌فایر/اسپیکر لازم است؛ راهنمای اتصال در README پروژه است. سرویس کامپیوتر فقط USB و فایل‌های این صفحه را منتقل می‌کند.

مرورگر برای میکروفون به localhost یا HTTPS نیاز دارد. بازکردن آدرس HTTP کامپیوتر روی گوشی کافی نیست. هیچ سرویس تشخیص گفتار ابری استفاده نمی‌شود.
